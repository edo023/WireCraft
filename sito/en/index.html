Artificial intelligence

An electrical CAD AI knows how to use

Traditional CAD tools are only windows and clicks. WireCraft also has a language: every command has a name, clear parameters and a structured answer. It's the same language AI assistants speak. So the AI does the repetitive work, and you keep the decisions.

Reads the project

Components, wires, terminals, cables and nets come out as JSON: the AI knows what's in the schematic and where, sheet by sheet.

Draws like a designer

Places symbols and wires, tags components, numbers wires, builds terminal strips, bill of materials and wiring table. One command per action, nothing hidden.

Checks the work

Cross reference with issues in red, duplicate wire numbers, protection and cable checks in single-line diagrams: the AI finds mistakes before commissioning.

You stay in charge

Every change is a command you can read, undo and redo by hand. The AI saves you hours; the signature on the project stays yours.

AI assistant → WireCraft

you › On sheet 3 add start and stop for the conveyor with a run lamp. Then number the wires and update the bill of materials.

Features

The whole workflow, from schematic to panel

A complete electrical CAD for machines and industrial automation panels. If you come from a traditional electrical CAD, the workflow will feel familiar, in a lightweight program that starts in an instant.

Projects and sheets

Projects with multi-sheet drawings, A3 border and an auto-filled title block. Add, move or compact sheets: references follow.

  • multi-sheet
  • revisions
  • stored sheets
  • per-customer settings

Electrical schematics

Orthogonal wires with automatic junctions, power rails, cross-sheet references and 52 IEC 60617 symbols drawn from scratch. Delete a symbol and the wire closes.

  • coloured wires
  • contact mirrors
  • multi-wire insertion

Automation

Component tagging in six modes, automatic wire numbering, live cross reference, tree navigator and "go to linked".

  • IEC 81346
  • duplicate numbers flagged
  • locked wires

Terminals, cables, PLC

Terminal strips placed with a line across wires, jumpers, connectors, cables with their cores and PLC I/O cards with addresses and bilingual comments.

  • terminal editor
  • loop diagrams
  • machine configurator

Lists and reports

Sheet index, bill of materials, terminal strips, wiring table, cable and I/O lists on the sheets, always updatable. Also in CSV and Excel.

  • parts database
  • price lists
  • labels

Panel layout

From schematic to a scaled mounting plate, with DIN rails, cable ducts and dimensioned drilling. The door layout puts buttons and lamps on the front.

  • layout manager
  • thermal calculation
  • drilling in CSV

Single-line diagrams

Distribution boards that size themselves: load current, protection rating, cable cross-section and voltage drop, with verification.

  • Ib ≤ In ≤ Iz
  • IEC 60364-5-52
  • breaking capacity

Translator

Dictionary in Italian, English, German, French and Spanish. A bilingual schematic with one command: functions, sheet titles and columns.

  • IT · EN · DE · FR · ES

Print and PDF

Dynamic PDF with sheet bookmarks and clickable references. Coloured wires and everything else in black, ready for the customer.

  • plant diagram
  • floor plan
  • terminal drawings

Get started

From download to first schematic in two minutes

  1. Download

    Get the latest Windows 10/11 64-bit build from the GitHub Releases page.

  2. Run

    Extract the ZIP and double-click wirecraft.exe. No installation, no account.

  3. Explore

    In the project manager press the sample project button: a complete plant opens, ready to browse and edit.

Developer? Build from source

You need Rust 1.95 or later and the Visual Studio Build Tools (C++).

git clone --recurse-submodules https://github.com/edo023/WireCraft.git
cd WireCraft
scripts/aggiorna-cadcraft.sh        # prepares the CAD engine
cargo run --release -p wirecraft    # starts the program

Every command and its parameters are in the command guide (Italian).

WireCraft is alpha software and the executable is not yet code-signed: on first launch Windows may show "Windows protected your PC". Choose More info → Run anyway.

FAQ

Everything you want to know

Is WireCraft really free?

Yes. WireCraft is open source under the MIT or Apache-2.0 license, your choice: use it for professional work with no licenses, subscriptions or sheet limits. You can also modify and redistribute it.

How do you use AI with an electrical CAD?

In WireCraft every command has a name and JSON parameters and returns a structured result. An AI assistant can write the sequence of commands that places symbols and wires, tags components, numbers wires and builds the lists, then read the cross reference to check the schematic. The 22-sheet sample project is built exactly this way.

The next step is connecting your assistant directly to the open project through the Model Context Protocol (MCP).

Can AI get a schematic wrong?

Yes, just like a person. That's why in WireCraft the AI never works behind your back: every change is a readable command you can review, undo and redo, and the cross reference flags issues. Decisions and responsibility stay with the designer.

Can I open my existing projects?

WireCraft reads and writes DWG and DXF files and recognises sheets, titles, cross references, wires and contacts of existing schematics. Electrical data lives in block attributes, lists in CSV and Excel: your projects stay yours.

Is the interface in English?

Not yet: the interface is currently in Italian, while the translator already produces schematics in English, German, French and Spanish. An English interface is a great place to contribute.

Which operating systems are supported?

The ready-made executable is for 64-bit Windows 10 and 11. The code is written in Rust on a cross-platform CAD engine, CADCraft, so developers can build it from source elsewhere.

Which standards does it follow?

Symbols follow IEC 60617, reference designations IEC 81346 and cable sizing in single-line diagrams IEC 60364-5-52. Calculations assist the designer: final verification and compliance of the installation stay with the engineer who signs it.
